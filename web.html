Phone Metrics

Real‑time battery, RAM usage, and FPS monitor

About the App

Phone Metrics is a lightweight utility that helps you see how your device performs in real time while you use apps and games. It focuses on showing useful information clearly without intrusive ads or complex setup.

Key Features

  • Battery level and charging status.
  • Estimated RAM usage in gigabytes (used vs total).
  • Live FPS estimation using an in‑app overlay badge.
  • Clean UI with an always‑visible metrics card inside the app.
  • No login, no cloud account, and no ads.

How It Works

The app reads basic system information directly from your device to calculate battery percentage, memory usage, and frame rate. All metrics are processed locally on the phone and are not sent to any server.
